# 🚀 Projetos em destaque

## ⚡ InverterModbusLib

Biblioteca desenvolvida em **C++/Arduino** para criar uma interface comum de comunicação com diferentes famílias de inversores fotovoltaicos através de **Modbus RTU**.

O projeto nasceu da necessidade de evitar implementações específicas para cada fabricante e evoluiu para uma arquitetura baseada em descritores, mapas de registradores e funções genéricas de leitura e escrita.

Entre os recursos desenvolvidos estão:

- suporte a diferentes famílias e fabricantes de inversores;
- leitura de informações do equipamento;
- leitura de grandezas elétricas;
- leitura vetorizada de fases, strings, baterias e EPS;
- leitura e configuração de parâmetros;
- manipulação de data e hora;
- controle de limite de potência;
- conversão automática de tipos e fatores de escala;
- otimizações para sistemas embarcados e uso de `PROGMEM`;
- arquitetura preparada para expansão com novos equipamentos.

O desenvolvimento é feito utilizando equipamentos reais sempre que possível, transformando a biblioteca também em uma plataforma para experimentação e validação de comunicação industrial.

## ☀️ Optimus Sun

Projeto voltado ao **monitoramento, integração e gerenciamento de sistemas fotovoltaicos**.

O Optimus Sun reúne diferentes áreas que me interessam: comunicação com equipamentos de campo, aquisição de dados, processamento de informações e desenvolvimento de ferramentas para operação de sistemas de energia.

O projeto também serve como ambiente para aplicar e validar soluções desenvolvidas em outros trabalhos, incluindo comunicação com inversores e integração de diferentes equipamentos.

É um projeto de evolução contínua, no qual hardware, protocolos industriais e software se encontram em uma aplicação prática.

## ❤️ Vital Registro

Aplicativo desenvolvido em **Python com Kivy** para registro e organização de dados pessoais.

O projeto começou com uma necessidade simples de manter registros de forma estruturada e evoluiu para uma aplicação Android independente, com armazenamento local e ferramentas para consulta dos dados.

Entre os recursos estão:

- registro de pressão arterial e pulso;
- registro de peso;
- data e hora configuráveis;
- observações;
- edição do histórico;
- exportação para CSV;
- armazenamento local;
- interface voltada para uso simples em dispositivos móveis.

Além da aplicação em si, o Vital Registro é um projeto no qual exploro desenvolvimento mobile com Python, persistência de dados, UX e distribuição de aplicações Android.
